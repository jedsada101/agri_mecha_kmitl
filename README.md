# Agricultural Mechatronics & Robotics — Course Website

เว็บไซต์ประกอบการสอนรายวิชา **เมคคาทรอนิกส์และหุ่นยนต์เกษตร** (Agricultural Mechatronics & Robotics)
หลักสูตร วศ.บ. วิศวกรรมเกษตรอัจฉริยะ (Agri-Intelligence Engineering) ชั้นปีที่ 3
สถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง

Bilingual (Thai / English) courseware for a 16-week, 3(2-2-5) undergraduate course.

---

## เปิดใช้งาน / Getting started

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้โดยตรง ไม่ต้องติดตั้งหรือ build อะไรเลย
Just open `index.html` in a browser — there is nothing to install and nothing to build.

หากต้องการเสิร์ฟผ่าน local server (เช่น เพื่อทดสอบบนมือถือในวงเดียวกัน):

```bash
python -m http.server 8000
```

เว็บไซต์ทำงานได้ทั้งแบบออนไลน์และออฟไลน์ — MathJax ถูกเก็บไว้ในโปรเจกต์แล้ว
ส่วนฟอนต์ Google Fonts และไอคอน Font Awesome จะ fallback ไปใช้ของระบบเมื่อไม่มีอินเทอร์เน็ต

## แนวทางที่ใช้ในการพัฒนา / Conventions

- **สองภาษา** — ทุกข้อความมีทั้งไทยและอังกฤษอยู่คู่กันใน HTML เป็น `data-lang-th` / `data-lang-en`
  แล้วให้ CSS ซ่อนภาษาที่ไม่ได้เลือกผ่าน `html[data-lang]` จึงไม่มีอาการข้อความกระพริบตอนโหลด
- **สมการ** — เขียนเป็น LaTeX ธรรมดา: inline ใช้ `\( ... \)`, display ใช้ `$$ ... $$` ภายใน `.eq`
  พร้อม `.eq__num` สำหรับเลขสมการ สมการที่อยู่ในรูปภาพใช้ HTML label วางทับบน SVG
  (`.fig-stage` + `.fig-label`) ไม่ใช้ SVG `<text>`
- **แบบทดสอบ** — ทุกบทมี pre-test และ post-test ระบบเก็บคะแนนลง localStorage
  และ post-test จะคำนวณพัฒนาการเทียบกับ pre-test ให้อัตโนมัติ
- **แอนิเมชัน** — สร้างด้วย `AMRAnim.create(id, {setup, update, reset})`
  หยุดเองเมื่อเลื่อนพ้นหน้าจอ และไม่เล่นอัตโนมัติถ้าผู้ใช้ตั้งค่า `prefers-reduced-motion`
- **ทุกบท** ประกอบด้วย วัตถุประสงค์ → pre-test → เนื้อหา → กิจกรรมในชั้นเรียน → ปฏิบัติการ
  → สรุป → post-test → รายการอ้างอิง
