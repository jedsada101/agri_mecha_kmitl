5.1 ฮาร์ดแวร์ของ PLC และตู้ควบคุม5.1 PLC hardware and the control cabinet

PLC ที่ใช้ในฟาร์มไม่ได้อยู่โดด ๆ แต่อยู่ในตู้ควบคุมที่มีอุปกรณ์อื่นประกอบอีกหลายอย่าง การรู้ว่าอะไรอยู่ตรงไหนช่วยให้ไล่ปัญหาได้เร็วขึ้นมาก เพราะปัญหาส่วนใหญ่ที่พบหน้างานไม่ได้อยู่ในโปรแกรม แต่อยู่ที่สายและแหล่งจ่ายไฟ A farm PLC never lives alone; it sits in a cabinet alongside several other devices. Knowing what is where speeds up fault-finding enormously, because most problems met on site are not in the program but in the wiring and the supplies.

The correct arrangement is for the PLC to energise a contactor coil, drawing only tens of milliamps, and let the contactor carry the motor current.

5.2 การเดินสาย I/O แบบ sinking และ sourcing5.2 Wiring the I/O: sinking and sourcing

นี่คือหัวข้อที่ทำให้นักศึกษาเสียเวลาในห้องปฏิบัติการมากที่สุด และเป็นสาเหตุอันดับหนึ่งของอาการ “ต่อครบแล้วแต่ไฟอินพุตไม่ติด” ปัญหาอยู่ที่ว่าเซนเซอร์อุตสาหกรรมมีสองตระกูลที่หน้าตาเหมือนกันแต่จ่ายสัญญาณกลับด้านกัน This is where students lose the most laboratory time, and the leading cause of “everything is connected but the input light stays off”. The trouble is that industrial sensors come in two families that look identical but deliver their signal in opposite directions.

เซนเซอร์ PNP (sourcing)PNP sensor (sourcing)

  • เมื่อทำงาน จะ จ่ายแรงดันบวก ออกมาที่สายสัญญาณWhen it triggers it supplies +24 V onto the signal wire.
  • ต่อเข้าอินพุตที่คอมมอนเป็น 0 V (เรียกว่าอินพุตแบบ sinking)Goes to an input whose common is tied to 0 V, a sinking input.
  • กระแสไหล จากเซนเซอร์ → เข้าขั้วอินพุต → ออกทางคอมมอนCurrent flows from the sensor into the input terminal and out through the common.
  • เป็นมาตรฐานที่พบมากที่สุดในยุโรปและในเครื่องจักรที่นำเข้าส่วนใหญ่The commonest standard in Europe and on most imported machinery.

เซนเซอร์ NPN (sinking)NPN sensor (sinking)

  • เมื่อทำงาน จะ ดึงสายสัญญาณลงกราวด์ ไม่ได้จ่ายแรงดันออกมาWhen it triggers it pulls the signal wire to 0 V rather than supplying anything.
  • ต่อเข้าอินพุตที่คอมมอนเป็น +24 V (เรียกว่าอินพุตแบบ sourcing)Goes to an input whose common is tied to +24 V, a sourcing input.
  • กระแสไหล จากคอมมอน → เข้าขั้วอินพุต → ออกทางเซนเซอร์ลงกราวด์Current flows from the common into the input and out through the sensor to 0 V.
  • พบมากในเครื่องจักรจากญี่ปุ่นและในอุปกรณ์ราคาประหยัดจากจีนCommon on Japanese machinery and on low-cost equipment from China.
ต่อสลับกันแล้วเกิดอะไรขึ้นWhat happens if they are swapped

ถ้าเอาเซนเซอร์ PNP ไปต่อกับอินพุตที่ตั้งคอมมอนไว้ที่ +24 V ทั้งสองฝั่งจะพยายามจ่ายแรงดันบวกเข้าหากัน จึงไม่มีความต่างศักย์คร่อมวงจรอินพุต ผลคือ ไม่มีอะไรเกิดขึ้นเลย ไฟอินพุตไม่ติดแม้เซนเซอร์จะทำงานถูกต้อง ซึ่งเป็นอาการที่หลอกให้คิดว่าเซนเซอร์เสียหรือโปรแกรมผิด อาการนี้ไม่ทำให้อุปกรณ์เสียหาย แต่กินเวลาไล่ปัญหาได้ทั้งบ่าย ให้ตรวจที่ขั้วคอมมอนก่อนเสมอ Connect a PNP sensor to an input whose common sits at +24 V and both ends try to push positive at each other, so no potential difference appears across the input circuit. The result is that nothing happens at all: the input light stays dark even though the sensor is working perfectly, which fools people into suspecting the sensor or the program. It damages nothing, but it can swallow an entire afternoon. Always check the common terminal first.

ตัวอย่างในงานเกษตรอัจฉริยะIn smart-farm practice

โรงคัดบรรจุที่ทยอยซื้ออุปกรณ์มาหลายรอบมักมีเซนเซอร์ทั้งสองตระกูลปนกันอยู่ในตู้เดียว ทางปฏิบัติที่ดีคือเลือกมาตรฐานเดียวทั้งโรงงาน (ส่วนใหญ่เลือก PNP) แล้วระบุไว้ในแบบ ถ้าจำเป็นต้องใช้เซนเซอร์ NPN ที่มีอยู่เดิม ให้ใส่รีเลย์อินเทอร์เฟซคั่นหนึ่งตัวแทนการแยกคอมมอนของการ์ดอินพุตออกเป็นสองกลุ่ม เพราะการมีคอมมอนสองแบบในการ์ดเดียวกันทำให้คนที่มาซ่อมต่อสับสนและเดินสายผิดในภายหลัง A packhouse that bought equipment in several waves usually ends up with both families in one cabinet. Good practice is to pick one standard for the whole plant — usually PNP — and state it on the drawings. Where an existing NPN sensor must be kept, insert an interface relay rather than splitting the input card’s commons into two groups: two different commons on one card is exactly what misleads the next person to work on it.

The device is wired normally closed, so the bit is 1 while things are still safe. Named E_STOP, a reader would take 1 to mean “pressed”, the exact inverse of the truth, and would write the next rung backwards. A name that states the bit’s real condition heads off that class of mistake entirely.

5.4 รีจิสเตอร์ข้อมูล5.4 Data registers

บิตเก็บได้เพียงจริงหรือเท็จ แต่งานเกษตรเต็มไปด้วยตัวเลข เช่น อุณหภูมิ 28.4 °C น้ำหนัก 2,350 g หรือจำนวนลังที่บรรจุไปแล้ว 147 ลัง ตัวเลขเหล่านี้เก็บใน รีจิสเตอร์ข้อมูล ซึ่งโดยทั่วไปกว้าง 16 บิต A bit holds only true or false, but agriculture is full of numbers: 28.4 °C, 2,350 g, 147 crates packed so far. These live in data registers, normally 16 bits wide.

$$ -32\,768 \;\le\; D_n \;\le\; 32\,767 \qquad\text{(16-bit signed)} $$
(5.1)
การล้นของรีจิสเตอร์ไม่มีสัญญาณเตือนRegister overflow announces itself to nobody

เครื่องบรรจุที่นับจำนวนถุงสะสมในรีจิสเตอร์ 16 บิต จะนับได้ถึง 32,767 ถุง หลังจากนั้นค่าจะพลิกเป็น −32,768 ทันทีโดยไม่มีการแจ้งเตือนใด ๆ ถ้าโรงงานบรรจุ 2,000 ถุงต่อวัน เหตุนี้จะเกิดขึ้นในสัปดาห์ที่สาม และรายงานผลผลิตจะติดลบ วิธีแก้คือใช้รีจิสเตอร์ 32 บิต (double word) สำหรับค่าสะสม หรือรีเซ็ตเป็นรอบและเก็บผลรวมไว้ที่ระบบบันทึกข้อมูลแทน A bagging machine totalising into a 16-bit register counts to 32,767, then flips straight to −32,768 with no warning at all. At 2,000 bags a day that happens in the third week, and the production report goes negative. The fixes are a 32-bit double word for accumulated values, or resetting per shift and keeping the running total in the data-logging system instead.

5.4.1 รีจิสเตอร์ที่ค่าไม่หายเมื่อปิดเครื่อง5.4.1 Registers that survive a power cut

5.5 ฟังก์ชันคณิตศาสตร์และการสเกลสัญญาณอนาล็อก5.5 Arithmetic and scaling an analogue signal

โมดูลอนาล็อกไม่ได้ส่งค่าเป็นองศาเซลเซียสหรือ mS/cm มาให้ แต่ส่งเป็น ตัวเลขดิบ ที่สะท้อนตำแหน่งของสัญญาณภายในพิสัยของ ADC หน้าที่ของเราคือแปลงมันกลับเป็นหน่วยทางวิศวกรรม ซึ่งเป็นงานที่ต้องทำในทุกโครงการที่มีเซนเซอร์อนาล็อก An analogue module does not deliver degrees Celsius or mS/cm; it delivers a raw count representing where the signal sits in the ADC’s range. Converting that back into engineering units is work every project with an analogue sensor must do.

$$ y \;=\; y_{\min} \;+\; \left( x_{\text{raw}} - x_{\min} \right) \frac{\,y_{\max} - y_{\min}\,}{\,x_{\max} - x_{\min}\,} $$
(5.2)
โดยที่where
  • \( x_{\text{raw}} \) — ค่าดิบที่อ่านได้จากโมดูลthe raw count read from the module
  • \( x_{\min}, x_{\max} \) — ค่าดิบที่ปลายล่างและปลายบนของพิสัย เช่น 0 ถึง 27,648 ของ Siemens หรือ 0 ถึง 4,000 ของ Deltathe raw counts at each end of the range, say 0–27,648 on Siemens or 0–4,000 on Delta
  • \( y_{\min}, y_{\max} \) — ค่าทางวิศวกรรมที่ปลายทั้งสองของพิสัยเซนเซอร์the engineering values at the two ends of the sensor’s range

5.5.1 กับดักการหารจำนวนเต็ม5.5.1 The integer-division trap

คำสั่งคณิตศาสตร์ของ PLC ส่วนใหญ่ทำงานกับจำนวนเต็ม การหารจะ ตัดเศษทิ้ง ไม่ใช่ปัดเศษ ลำดับของการคูณและหารจึงเปลี่ยนคำตอบได้อย่างมาก Most PLC arithmetic works on integers, and division truncates rather than rounds, so the order of multiply and divide changes the answer substantially.

ตัวอย่างคำนวณ 5.1 — เซนเซอร์อุณหภูมิในโรงเรือนWorked example 5.1 — A greenhouse temperature input

ทรานสมิตเตอร์ส่งสัญญาณ 4–20 mA แทนช่วง 0–50 °C เข้าโมดูลที่ให้ค่าดิบ 0–4,000 ขณะหนึ่งอ่านค่าดิบได้ 1,640 จงหาอุณหภูมิ และเขียนเป็นลำดับคำสั่งที่ปลอดภัยจากการตัดเศษ A 4–20 mA transmitter spans 0–50 °C into a module reading 0–4,000 raw. At one moment the raw value is 1,640. Find the temperature, and write it as an instruction order safe from truncation.

$$ y \;=\; 0 + 1640 \times \frac{50 - 0}{4000 - 0} \;=\; \frac{1640 \times 50}{4000} \;=\; 20.5\ ^\circ\text{C} $$
(5.3)

ถ้าเขียนโปรแกรมโดย หารก่อนคูณ จะได้ \( 1640/4000 = 0 \) เพราะเศษถูกตัดทิ้ง แล้วคูณ 50 ได้ 0 °C ซึ่งผิดสิ้นเชิง ลำดับที่ถูกต้องคือคูณก่อนเสมอ Program it divide-first and \( 1640/4000 = 0 \) after truncation, which times 50 gives 0 °C — completely wrong. Always multiply first.

และเพื่อเก็บทศนิยมหนึ่งตำแหน่งโดยไม่ต้องใช้เลขทศนิยม ให้คูณด้วย 10 เพิ่ม แล้วเก็บค่า 205 ไว้ในรีจิสเตอร์ โดยตกลงกันว่าหน่วยคือ 0.1 °C ซึ่งเป็นวิธีที่ใช้กันทั่วไปในงานอุตสาหกรรม To keep one decimal place without floating point, scale by a further ten and store 205, agreeing that the unit is 0.1 °C — the usual industrial practice.

ตัวอย่างในงานเกษตรอัจฉริยะIn smart-farm practice

ระบบผสมปุ๋ยอัตโนมัติต้องสเกลสัญญาณสามเส้นพร้อมกัน คือ EC (0–5 mS/cm), pH (0–14) และอัตราการไหล (0–50 L/min) โดยทั้งสามใช้สมการ (5.2) เหมือนกันแต่คนละค่าปลายพิสัย วิธีที่ทำให้โปรแกรมสะอาดคือเขียนบล็อกฟังก์ชันสเกลหนึ่งอันแล้วเรียกใช้สามครั้งด้วยพารามิเตอร์ต่างกัน แทนที่จะคัดลอกบรรทัดคำสั่งไปวางสามชุด ซึ่งเมื่อต้องแก้ค่าปลายพิสัยภายหลังจะลืมแก้ชุดใดชุดหนึ่งเสมอ An automated fertigation skid must scale three signals at once — EC (0–5 mS/cm), pH (0–14) and flow (0–50 L/min) — all through equation (5.2) but with different endpoints. The clean way is one scaling function block called three times with different parameters, rather than three copied-and-pasted instruction sets: when an endpoint changes later, someone always forgets one of the copies.

กลุ่มละ 2–3 คน · 4 ชั่วโมง (2 คาบ) · ห้องปฏิบัติการระบบอัตโนมัติGroups of 2–3 · 4 hours across two sessions · Automation laboratory

  • เซนเซอร์ความชื้นดินที่สอบเทียบแล้วจากปฏิบัติการที่ 3The soil-moisture probe calibrated in Laboratory 3
  • มัลติมิเตอร์ และหน้าจอ HMI หรือซอฟต์แวร์มอนิเตอร์ของผู้ผลิตA multimeter, and an HMI or the vendor’s monitoring software

ขั้นตอนการทดลองProcedure

  1. เดินสายเซนเซอร์ทั้งสองแบบWire both sensor types
    ต่อเซนเซอร์ PNP เข้าอินพุต X0 ให้ถูกขั้ว ทดสอบจนไฟติด จากนั้นต่อเซนเซอร์ NPN เข้า X1 บันทึกว่าต้องเปลี่ยนอะไรที่ขั้วคอมมอน และวัดแรงดันที่ขั้ว X ทั้งสองกรณีด้วยมัลติมิเตอร์ Wire the PNP sensor to X0 correctly and prove the light comes on, then the NPN sensor to X1. Record what had to change at the common terminal, and measure the terminal voltage in both cases.
  2. ทดลองต่อผิดโดยเจตนาGet it deliberately wrong
    สลับคอมมอนของ X0 ให้ผิดชนิด บันทึกอาการที่สังเกตได้และแรงดันที่วัดได้ที่ขั้วอินพุต อธิบายด้วยทิศทางการไหลของกระแสว่าทำไมจึงไม่มีอะไรเกิดขึ้น Move X0’s common to the wrong polarity. Record the symptom and the measured terminal voltage, and explain from the direction of current flow why nothing happens.
  3. สเกลสัญญาณ 4–20 mAScale the 4–20 mA input
    ป้อนสัญญาณที่ 4, 8, 12, 16 และ 20 mA บันทึกค่าดิบที่อ่านได้ในรีจิสเตอร์ พล็อตกราฟค่าดิบเทียบกระแส แล้วหาค่า \( x_{\min} \) และ \( x_{\max} \) จริงของโมดูล Inject 4, 8, 12, 16 and 20 mA, record the raw register value at each, plot raw against current, and determine the module’s actual \( x_{\min} \) and \( x_{\max} \).
  4. เขียนตรรกะการสเกลสองแบบWrite both scaling orders
    เขียนทั้งแบบคูณก่อนหารและแบบหารก่อนคูณลงในโปรแกรมเดียวกัน โดยเก็บผลลัพธ์ไว้คนละรีจิสเตอร์ บันทึกค่าทั้งสองที่ทุกจุดทดสอบลงตารางที่ 5.1 Implement both the multiply-first and divide-first orders in one program, results in separate registers, and record both at every test point in data sheet 5.1.
  5. ควบคุมด้วยแถบตายControl with a deadband
    ใช้เซนเซอร์ความชื้นดินจากปฏิบัติการที่ 3 สั่งไฟแสดงผลแทนวาล์ว โดยเปิดที่ต่ำกว่า 55 %VWC และปิดที่ 65 %VWC นับจำนวนครั้งการสลับใน 10 นาที จากนั้นลดแถบตายเหลือ 0 แล้วนับใหม่ Using the Laboratory 3 probe, drive a lamp in place of a valve: on below 55 %VWC, off at 65 %VWC. Count switching events over ten minutes, then collapse the deadband to zero and count again.
  6. ทดสอบการคงค่าในหน่วยความจำTest memory retention
    ตั้งตัวนับไว้สองตัว ตัวหนึ่งเป็น retentive อีกตัวเป็นธรรมดา นับให้ได้ค่าหนึ่ง แล้วตัดไฟ PLC 30 วินาที จ่ายไฟใหม่และบันทึกค่าของทั้งสองตัว Set up two counters, one retentive and one ordinary, count them up, remove power for 30 s, restore it and record both values.

การวิเคราะห์ผลAnalysis

  1. กราฟค่าดิบเทียบกระแสเป็นเส้นตรงหรือไม่ และค่า \( x_{\min} \) ที่วัดได้ตรงกับที่คู่มือระบุหรือไม่ ถ้าไม่ตรงจะกระทบผลการสเกลอย่างไรIs raw against current linear, and does the measured \( x_{\min} \) match the manual? If not, how does that affect the scaled result?
  2. ที่จุดทดสอบใดที่ผลแบบหารก่อนให้ค่าผิดมากที่สุด และเพราะเหตุใดจึงเป็นจุดนั้นAt which test point is the divide-first result worst, and why that point in particular?
  3. จำนวนครั้งการสลับลดลงกี่เท่าเมื่อใส่แถบตาย 10 %VWC และถ้ารีเลย์มีอายุหนึ่งล้านครั้ง อายุใช้งานต่างกันกี่ปีBy what factor did switching fall with a 10 %VWC deadband, and at a one-million-operation relay life, how many years does that difference represent?
  4. จากการทดลองตัดไฟ ตัวนับใดคงค่าไว้ได้ และเหตุใดจึงไม่ควรเก็บสถานะขั้นของลำดับการทำงานไว้แบบ retentiveWhich counter survived the outage, and why should a sequence’s step state nevertheless not be retentive?
  5. ถ้าต้องวัดอุณหภูมิช่วง −10 ถึง 60 °C ด้วยโมดูลเดิม สมการ (5.2) จะเปลี่ยนไปอย่างไร และต้องระวังอะไรเป็นพิเศษเรื่องค่าติดลบในรีจิสเตอร์If the range became −10 to 60 °C on the same module, how does equation (5.2) change, and what needs care about negative values in a register?

ความปลอดภัยSafety

ขั้นตอนที่ 6 ต้องตัดไฟให้ PLC ซึ่งต้องทำที่เบรกเกอร์ของชุดฝึกเท่านั้น ห้ามถอดขั้วต่อขณะจ่ายไฟ เพราะอาจเกิดอาร์กที่ขั้วและทำให้โมดูลเสียหาย ก่อนต่อเครื่องจำลองสัญญาณ 4–20 mA ให้ตรวจสอบว่าตั้งโหมดถูกต้อง เพราะการป้อนแรงดันเข้าช่องที่ตั้งไว้รับกระแสจะทำให้โมดูลอนาล็อกเสียหายถาวร และต้องตรวจขั้วบวกลบก่อนจ่ายไฟทุกครั้ง Step 6 removes power from the PLC, which must be done at the trainer’s breaker only — never unplug a connector while energised, as arcing at the pins can destroy a module. Before connecting the 4–20 mA simulator, confirm its mode: feeding voltage into a channel configured for current permanently damages an analogue module. Check polarity every time before applying power.

สรุปและคำศัพท์สำคัญSummary & key terms

  • ปัญหาหน้างานส่วนใหญ่อยู่ที่สายและแหล่งจ่ายไฟ ไม่ใช่ในโปรแกรม จึงควรไล่จากฮาร์ดแวร์ก่อนเสมอMost problems on site are in wiring and supplies, not the program, so check the hardware first.
  • วงจรหยุดฉุกเฉินต้องใช้รีเลย์นิรภัยภายนอก PLC ไม่พึ่งซอฟต์แวร์เพียงอย่างเดียวThe emergency-stop circuit needs a safety relay outside the PLC; software alone is not acceptable.
  • เซนเซอร์ PNP คู่กับอินพุตที่คอมมอนเป็น 0 V ส่วน NPN คู่กับคอมมอนที่ +24 V ต่อสลับกันแล้วจะเงียบสนิทโดยไม่มีอะไรเสียหายA PNP sensor pairs with a 0 V common, an NPN with a +24 V common; swap them and everything goes silent without anything breaking.
  • PLC ขับคอยล์ของคอนแทกเตอร์ ไม่ใช่ขับมอเตอร์โดยตรง เพราะกระแสเริ่มเดินสูงกว่าพิกัดหลายเท่าA PLC drives a contactor coil, never the motor itself, because starting current is many times the rating.
  • ชื่อสัญลักษณ์ที่ดีบอก สถานะของบิต ไม่ใช่ชื่ออุปกรณ์ เช่น ES_OK ไม่ใช่ E_STOPA good symbol states the bit’s condition, not the device: ES_OK, not E_STOP.
  • รีจิสเตอร์ 16 บิตล้นที่ 32,767 โดยไม่มีสัญญาณเตือน ค่าสะสมจึงต้องใช้ 32 บิตA 16-bit register overflows silently at 32,767, so accumulated totals need 32 bits.
  • ค่าตั้งและยอดสะสมควรเป็น retentive แต่สถานะขั้นของลำดับต้องไม่เป็น เพื่อให้เริ่มใหม่อย่างปลอดภัยเสมอSetpoints and totals should be retentive; a sequence’s step must not be, so restarts are always safe.
  • การสเกลใช้สมการ (5.2) และต้อง คูณก่อนหาร เสมอ เพราะการหารจำนวนเต็มตัดเศษทิ้งScaling follows equation (5.2) and must always multiply before dividing, since integer division truncates.
  • การเปรียบเทียบด้วยเกณฑ์เดียวทั้งเปิดและปิดทำให้เอาต์พุตกระพริบ ต้องใส่แถบตายตามสมการ (5.4)One threshold for both on and off makes an output chatter; add the deadband of equation (5.4).

คำศัพท์สำคัญKey terms

Sinking / sourcing
ทิศทางที่กระแสไหลเข้าหรือออกจากขั้ว ซึ่งกำหนดว่าเซนเซอร์ PNP หรือ NPN จะเข้ากันได้The direction current flows at a terminal, which decides whether a PNP or NPN sensor fits
Common terminal
ขั้วร่วมของกลุ่มอินพุต ซึ่งต่อไว้ที่ 0 V หรือ +24 V และเป็นจุดแรกที่ต้องตรวจเมื่ออินพุตไม่ทำงานThe shared terminal of an input group, tied to 0 V or +24 V, and the first thing to check when an input is dead
Symbol table
ตารางจับคู่แอดเดรสกับชื่อที่สื่อความหมาย เป็นเอกสารที่ทำให้โปรแกรมยังอ่านได้ในอีกหนึ่งปีThe map from addresses to meaningful names — what keeps a program readable a year later
Retentive memory
หน่วยความจำที่คงค่าไว้เมื่อไฟดับ ใช้กับค่าตั้งและยอดสะสม ไม่ใช้กับสถานะขั้นของลำดับMemory that survives a power cut: for setpoints and totals, never for a sequence step
Scaling
การแปลงค่าดิบจาก ADC เป็นหน่วยทางวิศวกรรมด้วยความสัมพันธ์เชิงเส้นสองจุดConverting a raw ADC count into engineering units through a two-point linear relation
Deadband
ช่องว่างระหว่างเกณฑ์เปิดกับเกณฑ์ปิด ที่ใส่เข้าไปเพื่อไม่ให้เอาต์พุตสลับถี่เกินไปThe gap between the on and off thresholds, added so an output does not switch too often
